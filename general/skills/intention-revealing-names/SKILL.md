# Intention-Revealing Names

A name that the program chooses for a function, method or class never consists only of
words that could name any code.

## Why

A name with no word for what the code does or makes sends every reader to the body, so
every call site reads as a question.

Source: Robert C. Martin, *Clean Code* (2008), chapter 2, "Use Intention-Revealing
Names".
